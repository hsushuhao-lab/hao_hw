## High-resolution originals

High-resolution raster concept sheets are retained in the final offline handoff ZIP. GitHub hosts lightweight SVG derivatives for stable static deployment and direct browser access. The visual design represented by both is the same source of truth.

## Public/private boundary

Public GitHub contains only game-ready/derived artwork and code. Original real-person source photographs should remain outside the public repository unless the people shown have separately approved public redistribution.
